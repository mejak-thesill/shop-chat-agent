# Shop AI Chat Agent — System Overview

## What is this system?
This system adds an AI-powered shopping assistant to a Shopify store.
The assistant helps customers find products, add items to cart, and proceed to checkout.
All assistant interactions are tracked to measure engagement, conversion, and revenue attribution.

## High-level flow
1. Customer opens the Shopify storefront
2. Chat widget loads in the browser
3. Messages are sent to the AI backend
4. AI suggests products or actions (add to cart, checkout)
5. User actions are tracked via events
6. Shopify webhooks confirm completed orders
7. Analytics dashboard displays performance metrics

## Key goals
- Improve shopping experience
- Measure assistant impact on revenue
- Attribute orders to assistant interactions
