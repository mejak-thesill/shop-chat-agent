# Event Tracking & Analytics

## Single source of truth
All analytics are derived from the `AssistantEvent` table.

This table stores:
- Assistant interactions
- Checkout clicks
- Shopify webhook events
- Order completions

No analytics logic depends on frontend-only state.


## Tracked Events

### assistant_add_to_cart
Triggered when the assistant adds a product to the cart.

Stored fields:
- productVariantId
- quantity
- conversationId

### assistant_checkout_click
Triggered when a user clicks a checkout link generated by the assistant.

Stored fields:
- checkoutUrl
- conversationId

### orders/create (Shopify webhook)
Triggered by Shopify when an order is completed.

Stored fields:
- rawPayload (full order)
- checkout_token


## Metric Definitions

### Checkout Clicks
Number of assistant-generated checkout link clicks.

Source:
AssistantEvent(eventType = 'assistant_checkout_click')

### Orders
Number of completed Shopify orders.

Source:
AssistantEvent(eventType = 'orders/create')

### Conversion Rate
orders / checkout_clicks

### Revenue
Sum of (price × quantity) from Shopify order line items.

### AOV
total_revenue / total_orders
